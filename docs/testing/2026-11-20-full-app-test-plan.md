# Test Plan: Budget Tracker Full-App End-to-End Suite

- **Date**: 2026-11-20
- **Stack**: TypeScript Monorepo (`pnpm` + Turborepo) — `@repo/contracts` (Zod + Vitest), `@repo/api` (Hono + Drizzle ORM + PostgreSQL/PGlite + Vitest), `@repo/mobile` (Expo SDK 58 + Expo Router + React Native 0.88 + NativeWind + TanStack Query + `jest-expo` + Expo Web)
- **Scope**: All 6 project domains end-to-end:
  1. Auth, Sessions & Version Gate (`packages/contracts/src/auth.schema.ts`, `apps/api/src/capabilities/auth/*`, `apps/api/src/core/auth/*`, `apps/api/src/core/meta.ts`, `apps/mobile/src/features/auth/*`, `apps/mobile/src/common/components/version-gate.tsx`)
  2. Transactions, Fast Capture Calculator, Splits & Custom Categories (`packages/contracts/src/{money,calculator,transactions.schema}.ts`, `apps/api/src/capabilities/{transactions,categories,shared}/*`, `apps/mobile/src/features/transactions/*`)
  3. Wallets & Balance Reconciliation (`packages/contracts/src/reconciliation.schema.ts`, `apps/api/src/capabilities/{wallets,reconciliation}/*`, `apps/mobile/src/features/dashboard/components/wallet-manager-modal.tsx`, `apps/mobile/src/features/reconciliation/*`)
  4. Financial Planning — Category Envelopes, Recurring Commitments, Safe-to-Spend, Sinking Funds & Quick Presets (`packages/contracts/src/{category-budget,recurring,sinking-funds,presets}.schema.ts`, `apps/api/src/capabilities/planning/*`, `apps/mobile/src/features/dashboard/components/{safe-to-spend,envelope-budgets,sinking-funds}-card.tsx`)
  5. Dashboard Analytics & Settings (`packages/contracts/src/dashboard.ts`, `apps/api/src/capabilities/settings/*`, `apps/mobile/src/features/{dashboard,settings}/*`)
  6. Data Portability & Account Maintenance (`packages/contracts/src/portability.schema.ts`, `apps/api/src/capabilities/portability/*`, `apps/mobile/src/features/portability/*`)
- **Delete / Cleanup Support**: Yes (API provides `DELETE` endpoints for wallets, transactions, budgets, recurring commitments, sinking funds, quick presets, plus `POST /v1/account/clear-transactions`, `POST /v1/account/reset-demo`, and PGlite isolated per-suite DB; live browser tests registered disposable QA user `qa-e2e-1795189614@example.com`).
- **Triggered Conditional Classes**: Workflow State & Locks (`recurringCommitments` settle/unmark, `sinkingFunds` completion); Relational & Foreign Keys (wallet/category references & delete guards); Search & Filter (`TransactionsScreen` multi-filter state); Date & Time Boundaries (`periodMonth`, `safe-to-spend?date=`, leap-year/month rollover); Data Portability / File Import-Export (CSV/JSON); Concurrency & Idempotency (CAS settle, concurrent register, zero-delta reconciliation); Side Effects (atomic wallet balances & category `usageCount`).
- **Runners**: `test-runner` (`Model: "flash"` — Vitest, Jest/`jest-expo`, `tsc --noEmit`, lint), `browser` (`Model: "flash"` — Expo Web live UI verification at `http://localhost:8081`, host-verified via `BROWSER_HOST_FACTS`).
